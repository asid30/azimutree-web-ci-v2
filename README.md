# Landing Page Azimutree

Website informasi aplikasi Android Azimutree untuk pemetaan dan survei lokasi kesehatan hutan, dilengkapi panduan penggunaan, template Excel, dan informasi penghapusan akun.

🌐 **Akses website:** [Azimutree](https://azimutree.heavysnack.my.id/)

Dibangun dengan HTML, CSS, dan JavaScript. File website berada di folder `site/` dan diterbitkan melalui GitHub Pages.
